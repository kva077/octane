# Fuel Octane Estimator for BMW MGU (iDrive 7)

**Неофициальный хобби-проект.** Приложение оценивает октановое число топлива в баке по косвенным признакам работы двигателя (коррекции УОЗ, задержке из-за детонации).

- Приложение **не является** официальным продуктом BMW. Оно не одобрено и не поддерживается BMW AG.
- Вмешательство в CAN-шину и чтение сырых сигналов может привести к ошибкам в работе ЭБУ, сбоям других систем и **потере гарантии**.
- Используйте приложение **только на стоящем автомобиле или на закрытой трассе**. Не отвлекайтесь на экран во время движения.
- Автор не несёт ответственности за любые повреждения автомобиля, травмы или финансовые потери, возникшие в результате использования этого кода.

## Что делает приложение

1. Считывает с CAN-шины (через SDK `cauliflowermossgrape/idrive7-apps`) сигналы:
   - угол опережения зажигания,
   - долгосрочную и краткосрочную коррекцию УОЗ,
   - задержку из-за детонации (knock retard),
   - температуру охлаждающей жидкости,
   - обороты двигателя,
   - массовый расход воздуха (нагрузка).
2. Накапливает статистику коррекций за последние 5 минут.
3. Отсеивает прогревочные и переходные режимы.
4. Вычисляет усреднённую коррекцию и переводит её в шкалу 80–100 октановых единиц.
5. Отображает крупное значение (например, `≈95`), статус сбора данных и график коррекций.

## Установка на MGU

### Требования
- Автомобиль BMW с MGU (iDrive 7).
- Root SSH-доступ к головному устройству.
- Node.js 18+ на компьютере для сборки/упаковки.
- Установленный SDK и утилиты из репозитория [`cauliflowermossgrape/idrive7-apps`](https://github.com/cauliflowermossgrape/idrive7-apps).
